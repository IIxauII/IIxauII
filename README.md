## 🚀 Currently building — [hnch.dev](https://hnch.dev)

**Local-first pointing poker for agile teams.** Everyone picks a card privately, all cards flip
at once — no anchoring on the loudest voice in the room. No accounts, no setup.

Three clients, one protocol — half the team on phones, half in a terminal, same session:

```sh
npm i -g @xauyxau/hnch
hnch create        # start a room
hnch join K7P9MR   # or join one
```

Session state is a **Yjs CRDT living on the clients**. The relay is deliberately
*content-blind* — it forwards opaque binary updates and never parses votes, names, or ticket
titles. Conflicts can't happen, offline is the normal case, and there's nothing to leak.
